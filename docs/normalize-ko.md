## 1. 개요

### 1.1 목적

SLM이 추출한 원문 표현을 캡처 시각 기준의 절대 시각으로 바꾸는 규칙을 정의한다. SLM은 날짜를 계산하지 않는다(spec 5장). 계산은 이 문서의 규칙만 따른다.

### 1.2 입력과 출력

```python
resolve(date_expr, time_expr, duration_expr, captured_at, defaults) -> Resolved | None
```

| 입력 | 예 | 비고 |
| --- | --- | --- |
| `date_expr` | "다음 주 화요일" | 시각이 섞여 있어도 된다("내일 오후 3시") |
| `time_expr` | "오후 3시 반", "3시부터 5시까지" | |
| `duration_expr` | "한 시간 반" | |
| `captured_at` | 2026-11-02T15:24+09:00 | UTC 오프셋 필수. 처리 시각이 아니라 캡처 시각이다 |

| 출력 필드 | 의미 |
| --- | --- |
| `start`, `end` | 시간대가 붙은 절대 시각 |
| `all_day` | 시각 없이 날짜만 있으면 true. `end`는 다음 날 0시 |
| `assumed` | 추정으로 채운 항목. 후보 카드에 "추정"으로 표시한다 (spec 6.2) |

해석할 수 없으면 `None`을 돌려준다. 호출자는 일정 후보를 할 일로 강등한다 (spec 5.1).

### 1.3 `assumed` 값

| 값 | 붙는 경우 |
| --- | --- |
| `date` | 요일 없는 "다음 주", "주말", "월말"처럼 날짜를 추정한 경우. 날짜 없이 시각만 있는 경우 |
| `time` | "오후", "점심"처럼 시각 없는 모호 표현에 기본값을 쓴 경우 |
| `meridiem` | 오전·오후 표시 없는 "3시"를 추정한 경우 |
| `duration` | 끝 시각이나 기간이 없어 기본 기간을 쓴 경우 |

## 2. 날짜 규칙

규칙은 아래 순서로 시도하며 처음 맞는 규칙을 쓴다. 입력은 공백을 없애고 끝의 조사(에, 쯤, 경, 까지 등)를 뗀 뒤 해석한다.

| 순서 | 표현 | 결과 | 추정 |
| --- | --- | --- | --- |
| 1 | `2026-12-01`, `2027년 3월 2일` | 그 날짜 | |
| 2 | `11월 10일`, `11/20` | 올해 그 날짜. 7일 넘게 지났으면 내년 | |
| 3 | `12월 말`, `2월 중순` | 말일·15일·1일 | 예 |
| 4 | `다음 달 5일`, `이번 달 말`, `월말`, `다음 달 초` | 해당 월의 그 날 | 일 지정 없으면 예 |
| 5 | `3일 후`, `이틀 뒤`, `열흘 뒤`, `보름 후` | 오늘 + N일 | |
| 6 | `일주일 뒤`, `2주 후`, `두 주 뒤` | 오늘 + N주 | |
| 7 | `한 달 뒤`, `3개월 후` | 같은 날짜의 N개월 뒤 (말일 보정) | |
| 8 | `오늘`, `내일`, `모레`, `내일모레`, `글피`, `어제`, `그제` | 오늘 기준 상대 날짜 | |
| 9 | `주말`, `이번 주말`, `다음 주말` | 그 주 토요일 | 예 |
| 10 | `다음 주 화요일`, `이번 주 금요일`, `화요일` | 아래 2.1 | |
| 11 | `다음 주`, `차주` (요일 없음) | 그 주 금요일 | 예 |
| 12 | `15일` | 이번 달. 지났으면 다음 달 | |

### 2.1 주와 요일

- 주는 월요일에 시작한다
- 주 접두어: 이번·금(0), 다음·담·차·내(+1), 다다음(+2), 지난·저번(-1), 지지난(-2)
- 접두어가 있으면 해당 주의 그 요일이다. 결과가 과거일 수 있으며, 과거 날짜는 검증 단계(spec 5장 5단계)가 거른다
- 요일만 있으면 오늘 이후 가장 가까운 그 요일이다. 오늘과 같은 요일이면 다음 주다. 오늘을 뜻했다면 "오늘"이라고 말했을 것으로 본다

## 3. 시각 규칙

### 3.1 시각 표현

| 표현 | 예 | 결과 |
| --- | --- | --- |
| N시 (반 \| M분) | 3시 반, 10시 20분, 3시 삼십분 | |
| HH:MM | 15:30, 오후 2:30 | |
| 고유어 시 | 세 시, 열한시 | "한 시간"처럼 뒤에 "간"이 오면 시각이 아니다 |
| 정오, 자정 | | 12:00, 다음 날 00:00 |
| 범위 | 3시부터 5시까지, 오후 3시~5시 | 끝 시각은 시작의 오전·오후를 물려받는다. 끝이 시작보다 이르면 12시간 뒤, 그래도 이르면 다음 날 |
| 상대 시각 | 한 시간 뒤, 30분 후 | 캡처 시각 + 기간 |

### 3.2 오전·오후 판정

| 앞말 | 1~11시 | 12시 |
| --- | --- | --- |
| 새벽, 아침, 오전 | 그대로 | 0시 |
| 오후, 저녁, 낮 | +12 | 12시 |
| 점심 | 11시는 그대로, 1~2시는 +12 | 12시 |
| 밤 | 6~11시는 +12. 1~5시는 다음 날 새벽 | 다음 날 0시 |
| 없음 | 1~6시는 +12, 7~11시는 그대로 (`meridiem` 추정) | 12시 |
| (13시 이상, 0시) | 24시간제로 그대로 | |

표시가 없을 때의 판정은 업무 시간 가정이다. 1~6시 약속은 대부분 오후다.

### 3.3 모호 표현 기본값

시각 없이 때를 나타내는 말만 있으면 기본값을 쓰고 `time`을 추정으로 표시한다. 값은 맥락 사전 `defaults`(spec 8.3)로 바꿀 수 있다.

| 표현 | 기본값 |
| --- | --- |
| 새벽 | 06:00 |
| 아침, 오전 | 09:00 |
| 점심 | 12:00 |
| 오후, 낮 | 14:00 |
| 저녁 | 19:00 |
| 밤 | 21:00 |
| 기간 미지정 | 60분 |

## 4. 날짜와 시각의 결합

| 날짜 | 시각 | 결과 |
| --- | --- | --- |
| 있음 | 있음 | 그 날짜의 그 시각. 시각의 `day_offset`(밤 12시 등)을 더한다 |
| 있음 | 없음 | 종일 일정 |
| 없음 | 있음 | 오늘. 그 시각이 캡처 시각 이전이면 내일 (`date` 추정) |
| 해석 불가 | — | `None` |

끝 시각은 범위 표현 → 기간 표현 → 기본 기간 순으로 정한다.

## 5. 범위 밖 표현

다음은 현재 해석하지 않고 `None`을 돌려준다. 실사용 수정 기록(spec 11.2)을 보고 규칙을 추가한다.

- 막연한 때: 언젠가, 나중에, 조만간
- 맥락이 필요한 표현: "그날", "회의 끝나고"
- 한자어 날짜 수: "삼 일 뒤" (아라비아 숫자와 고유어 일수만 지원)
- 교대 근무 패턴 (spec 16.4, 현장노동자 팩에서 추가)
