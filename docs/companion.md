# Orbit Companion 명세 (v0.1)

| 항목 | 내용 |
| --- | --- |
| 상태 | M1 구현 기준 |
| 구현 | `companion/` (Kotlin, Jetpack Compose) |
| 상위 문서 | [spec.md](spec.md) 3장, [ingest-api.md](ingest-api.md) |

## 1. 개요

### 1.1 목적

Companion은 갤럭시 폰에서 통화 녹음·음성 녹음·공유 입력을 모아 홈서버로 전달하는 안드로이드 앱이다. 판단은 하지 않고 수집·필터·전송만 한다.

### 1.2 M1 범위

| 기능 | 포함 | 비고 |
| --- | --- | --- |
| 공유 인텐트 수신 | 예 | 텍스트, 오디오, 이미지, PDF |
| 통화·음성 녹음 폴더 감시 | 예 | 스펙상 M2 항목을 앞당김 |
| 통화 기록 첨부 | 예 | 상대 이름·번호·방향·통화 시간 |
| 전송 큐 (Room) | 예 | |
| 포그라운드 서비스, 부팅 시 재시작 | 예 | |
| 하트비트 | 예 | 15분 |
| 알림 수집, SMS, 위치 | 아니오 | M3 이후 |
| QR 페어링 | 아니오 | 토큰 직접 입력으로 대체 |

### 1.3 요구 환경

| 항목 | 값 |
| --- | --- |
| Android | 11 (API 30) 이상 |
| 기기 | One UI 기본 통화 녹음을 쓰는 갤럭시 기기 |
| 배포 | 사이드로드 APK. 스토어 정책상 막히는 `MANAGE_EXTERNAL_STORAGE`를 사용한다 |

Android 10 이후 서드파티 앱은 통화 음성을 직접 녹음할 수 없다. Companion은 녹음하지 않으며, OS 기본 녹음 앱이 만든 파일을 읽기만 한다.

## 2. 수집 경로

### 2.1 녹음 폴더 감시

| 폴더 (기본값) | `payload.origin` |
| --- | --- |
| `/storage/emulated/0/Recordings/Call` | `call` |
| `/storage/emulated/0/Recordings/Voice Recorder` | `voice` |

녹음 앱 저장 위치는 기종과 One UI 버전마다 다르다. 두 폴더는 앱의 "녹음 폴더" 항목에서 바꾼다.

- 경로는 내부 저장소 기준 상대 경로 또는 절대 경로다. 비우면 그 종류는 감시하지 않는다
- 칸 아래에 폴더 존재 여부와 오디오 파일 수를 보여 준다
- **녹음 폴더 찾기**: 내부 저장소를 5단계 깊이까지 훑어(`Android/`와 숨김 폴더 제외) 오디오 파일이 있는 폴더를 최근 수정 순으로 최대 10개 보여 준다. 항목의 **통화로**·**음성으로**를 누르고 **폴더 저장**을 누르면 적용된다
- 저장하면 수집 서비스를 다시 시작해 새 폴더에 감시를 걸고 바로 훑는다. `watchSince` 이후 파일만 보내는 규칙은 그대로다
- 하위 폴더는 감시하지 않는다. 녹음 앱이 날짜별 하위 폴더를 만들면 찾기 결과의 하위 폴더를 지정한다

동작 규칙:

1. `FileObserver`가 `CLOSE_WRITE`·`MOVED_TO`를 받으면 해당 파일을 검사한다
2. 10분마다, 그리고 서비스 시작 시 폴더 전체를 다시 훑어 놓친 파일을 보충한다. 아직 없는 폴더는 이때 감시를 건다
3. 다음 파일은 큐에 넣지 않아야 한다
   - 확장자가 `m4a`, `mp3`, `ogg`, `wav`가 아닌 파일
   - 수정 시각이 수집을 처음 켠 시각(`watchSince`)보다 이른 파일. 기존 녹음 전체가 한꺼번에 올라가는 것을 막는다
   - 재생 길이가 2초 미만인 파일
   - 경로·크기·수정 시각이 모두 같아 이미 처리한 파일
4. 수정 후 3초가 지나지 않은 파일은 쓰는 중으로 보고 건너뛴다. 쓰기가 끝나면 `CLOSE_WRITE`로 다시 들어온다
5. 녹음 원본은 옮기거나 지우지 않는다. `captured_at`은 파일 수정 시각이다

### 2.2 통화 기록 첨부

`origin`이 `call`인 녹음에는 대응하는 통화 기록을 `payload.call`로 첨부한다. 화자 식별과 맥락 사전 별칭 해석(spec 5장)에 쓴다.

| 항목 | 규칙 |
| --- | --- |
| 권한 | `READ_CALL_LOG`. 거부하면 첨부 없이 녹음만 보낸다 |
| 매칭 | 통화 종료 시각(시작 시각 + 통화 시간)이 파일 수정 시각과 2분 이내인 기록 중 가장 가까운 것 |
| 검색 범위 | 파일 수정 시각 기준 6시간 전부터 2분 후까지 |
| 이름 | 통화 기록에 캐시된 연락처 이름. 없으면 생략한다 |
| 제외 규칙 | 두지 않는다. 개인용이며 본인이 참여한 통화만 대상이다 (spec 3.2) |

```json
"call": {
  "number": "010-1234-5678",
  "name": "홍길동",
  "direction": "incoming",
  "started_at": "2026-11-02T15:20:12+09:00",
  "duration_s": 228
}
```

`direction`은 `incoming` | `outgoing` | `other`다.

### 2.3 공유 인텐트

- 대상: `ACTION_SEND`(텍스트·오디오·이미지·PDF), `ACTION_SEND_MULTIPLE`(오디오·이미지·PDF)
- 텍스트는 `type: share` 이벤트로 보낸다. `EXTRA_SUBJECT`가 있으면 `title`로 쓴다
- 파일은 공유 URI 권한이 일시적이므로 앱 전용 저장소로 복사한 뒤 큐에 넣고, 전송이 끝나면 복사본을 지운다
- 오디오는 `type: audio`, 그 밖의 파일은 `type: share`로 보낸다
- 화면 없이 처리하고 토스트로 결과만 알린다

## 3. 전송

### 3.1 큐

모든 입력은 Room `outbox` 테이블을 거친다. 서버가 수락하거나 중복으로 판정하면 행을 지운다. 남아 있는 행이 곧 전송 대기 목록이다.

### 3.2 전송 작업

전송은 WorkManager 작업(`UploadWorker`)이 맡는다. 큐에 항목이 들어올 때, 하트비트 주기마다, 사용자가 "지금 전송"을 누를 때 예약된다.

| 상황 | 동작 |
| --- | --- |
| 2xx | 큐에서 제거, 복사본 삭제, 마지막 전송 시각 갱신 |
| 401·403 | 작업 중단, 오류 표시. 다음 예약 시점까지 재시도하지 않는다 |
| 그 밖의 4xx | 해당 항목 실패 횟수 증가. 5회에 도달하면 자동 재시도 대상에서 빠진다 |
| 5xx·네트워크 오류 | 지수 백오프(30초 시작)로 작업 재시도 |
| 원본 파일 없음 | 항목 제거, 오류 표시 |
| Wi-Fi 전용 설정 + 과금 망 | 오디오만 보류하고, 비과금 망 연결 시 재시도 |

"지금 전송"은 실패 횟수를 초기화해 재시도 중단 항목도 다시 보낸다.

### 3.3 하트비트

15분 주기 WorkManager 작업이 `POST /heartbeat`를 보낸다. `listener_ok`는 수집이 꺼져 있으면 `true`이고, 켜져 있으면 서비스가 동작하면서 모든 파일 접근 권한이 유지될 때만 `true`다. 수집이 켜져 있는데 서비스가 죽어 있으면 이때 다시 띄운다.

## 4. 설치와 설정

### 4.1 빌드

```sh
cd companion
./gradlew assembleDebug
# 출력: app/build/outputs/apk/debug/app-debug.apk
```

JDK 17 이상과 Android SDK(platform 36)가 필요하다. SDK 경로는 `local.properties`의 `sdk.dir` 또는 `ANDROID_HOME`으로 지정한다.

### 4.2 초기 설정 절차

1. 서버에서 `orbit-server device add galaxy-01`로 토큰을 발급한다
2. 폰과 서버를 같은 tailnet에 연결한다
3. APK를 설치하고 앱에서 서버 주소(예: `http://homeserver:8787`)와 토큰을 입력한 뒤 "저장 및 연결 확인"을 누른다. "연결됨 · 기기 galaxy-01"이 표시되어야 한다
4. 권한 항목을 모두 허용한다: 모든 파일 접근, 알림, 통화 기록, 배터리 최적화 예외
5. One UI 설정에서 앱 배터리 사용을 "제한 없음"으로 둔다. 그렇지 않으면 OS가 서비스를 종료할 수 있다
6. "통화·음성 녹음 자동 전송"을 켠다. 이 시점 이후의 녹음만 전송된다

### 4.3 네트워크 보안

앱은 tailnet 주소로의 HTTP를 허용한다. 전송 구간 암호화는 WireGuard가 맡는다. tailnet 밖 주소를 서버 주소로 써서는 안 된다.

## 5. 프라이버시

- 통화 녹음에는 상대방의 음성이 들어 있다. 녹음 자체의 적법성과 고지 원칙은 [spec.md](spec.md) 9.5를 따른다
- 연락처별 제외 규칙은 두지 않는다. 수집을 켜면 감시 폴더의 모든 새 녹음이 상대 정보와 함께 전송된다
- 앱은 녹음 원본을 수정하거나 지우지 않는다
